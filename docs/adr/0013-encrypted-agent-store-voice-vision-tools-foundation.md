# ADR 0013：加密 Agent 存储、语音/视觉/工具基础切片

## 状态

Accepted；存储切片已按 IOS-15 落地。工具授权域层已实现，但工具执行/隐私中心 UI、语音和视觉切片未实现

## 背景

用户要求优先推进四块设计能力：

1. IOS-15：本地会话/记忆从 JSON 升级到加密 SQLite。
2. M2：实时语音通话。
3. M3：摄像头/屏幕理解。
4. 工具调用与隐私中心。

这些能力跨越存储、系统权限、音频、视觉和模型编排，不能在一次实现中承诺全部产品级功能；本 ADR 先固化安全基线和四个可验证切片。

## 目标

### 3. 加密 Agent 存储

1. 会话与记忆不再保存明文 JSON。
2. 使用系统 SQLite 存放记录，敏感 payload 使用 CryptoKit AES-GCM 加密。
3. 256-bit 数据密钥保存在 iOS/macOS Keychain，不落入普通沙盒文件。
4. 首次启动读取旧 JSON 并迁移；迁移成功后删除旧明文文件。
5. 清除记忆同时删除 SQLite 内容、缓存和旧 JSON。
6. 保留现有 `AgentMemoryStore` API，调用方不需要感知存储细节。
7. 清除记忆时先销毁 Agent 数据密钥，再删除 SQLite 密文；旧数据库或备份不可恢复。后续写入创建新密钥。

### 7. 工具调用与隐私中心

1. 定义六个确定性本地工具：提醒、计时、查日程、建日程、查联系人、查词。
2. 每个工具有独立授权状态，默认拒绝。
3. 工具执行只返回结构化结果；失败时返回结构化错误，不编造成功。
4. 隐私中心展示权限、工具授权、会话/记忆规模和清除入口。

### 5. 语音基础切片

1. 接入系统麦克风、语音识别和系统 TTS。
2. 音频会话使用 voice-chat 语义，辅助回声消除。
3. 用户手动开始/停止；识别结果先注入文字聊天链路。
4. TTS 播放可打断；当前切片不承诺无人值守全双工打断。

### 6. 视觉基础切片

1. 接入相机单帧采集。
2. 使用 Vision 框架做本地 OCR。
3. OCR 结果作为文字上下文进入本地模型，不落盘。
4. 当前切片不承诺 VLM 直接理解图像和连续关键帧。

## 非目标

- 不引入第三方 SQLCipher 依赖；本版采用 SQLite + 行级 AES-GCM 的平台内方案。
- 不实现向量索引和语义召回。
- 不实现无人值守全双工语音、TTS 缓存或 P50/P90 语音基准。
- 不实现连续视频理解、关键帧滚动上下文和 VLM 图像输入。
- 不把模型自动生成的工具调用直接执行；工具调用先由用户在工具面板显式触发，后续再开放模型意图解析。

## 数据与状态模型

SQLite 表：

```sql
CREATE TABLE IF NOT EXISTS agent_blob (
  kind TEXT PRIMARY KEY,
  payload BLOB NOT NULL,
  updated_at INTEGER NOT NULL
);
```

- `kind = facts`：加密后的记忆数组 JSON。
- `kind = transcript`：加密后的最近会话数组 JSON。
- `payload = AES.GCM.seal(plaintext JSON, key).combined`。
- `agent_tool_grants(tool TEXT PRIMARY KEY, granted INTEGER, updated_at INTEGER)` 也只保存布尔授权，不保存用户内容。

Keychain：

```text
service: com.startthree.edgeassistant
account: agent-store-master-key
```

Tavily 检索 API Key 使用独立 Keychain account（`tavily-search-api-key`），可保存、更新和显式删除；删除 Key 时关闭联网检索开关。

## 关键交互

### 存储

1. 打开 SQLite；表不存在则创建。
2. 若旧 `agent-memory.json` / `conversation.json` 存在，解密层迁移后删除。
3. 读取时 AES-GCM 解密并校验完整性；失败返回空数据并报告错误，不静默当作新库。
4. 写入前序列化为 JSON，再加密为单条记录。
5. 清除数据时先删除 Agent 数据密钥；密钥删除成功后再清空 SQLite 行与旧 JSON。若密钥删除失败，保留旧密文并向 UI 报错。

### 工具（当前已实现授权存储）

1. 用户在工具面板选择动作并填写最小参数。
2. 面板检查授权；未授权先请求系统权限。
3. 执行后显示结构化结果或错误。
4. 隐私中心可逐项撤销授权并清除数据。

当前代码只交付 `LocalAgentTool` 枚举、默认拒绝规则和 `ToolGrantStore` 持久化；上述面板、系统权限编排和确定性工具执行仍待后续切片。

### 语音

1. 用户点击开始 → 请求麦克风/语音识别授权。
2. `AVAudioSession` 切换到 playAndRecord + voiceChat。
3. Speech 框架实时转写；停止后进入现有聊天发送链路。
4. 系统合成器朗读助手回复；再次录音或点击停止会打断 TTS。

### 视觉

1. 用户打开视觉面板 → 请求相机授权。
2. 手动拍摄单帧。
3. Vision OCR 在本机识别文本。
4. 识别文本临时进入输入框，不写入相册或数据库。

## 边界与错误处理

- Keychain 读取失败：不创建可预测密钥；报“无法解锁本地加密数据”。
- SQLite 打开/读写失败：返回结构化错误，不退回明文 JSON。
- 迁移失败：保留旧 JSON，不删除原始数据。
- 麦克风/语音识别/相机拒绝：对应功能禁用并说明；文字聊天继续可用。
- 工具权限拒绝：显示权限缺失；不伪造结果。

## 验收清单

### 存储切片

- [x] 写入记忆/会话后，SQLite 文件中不包含明文关键词。
- [x] 旧 JSON 迁移后删除。
- [x] 重启后记忆/会话可恢复。
- [x] 清除后 SQLite 内容清空。
- [x] 清除前先销毁 Agent 数据密钥。
- [x] Tavily API Key 可独立删除，删除后关闭联网检索。

### 工具/隐私切片

- [x] 工具默认未授权。
- [x] 授权状态可按工具持久化读取和撤销。
- [ ] 每个确定性本地工具实现可调用执行器。
- [ ] 本地查词不联网。
- [ ] 提醒、计时、日程、联系人返回结构化结果。
- [ ] 隐私中心 UI 可逐项授权/撤销并清除数据。

### 语音切片

- [ ] 权限拒绝时 UI 明确禁用。
- [ ] 语音识别结果进入文字聊天。
- [ ] TTS 可打断。

### 视觉切片

- [ ] 相机拒绝时 UI 明确禁用。
- [ ] 拍摄单帧仅内存处理。
- [ ] OCR 文本进入输入框，不落盘。
