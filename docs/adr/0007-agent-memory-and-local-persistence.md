# ADR 0007: Agent 记忆与本地持久化方向

## 状态

已接受（方向）；IOS-15/IOS-18 第一阶段已分别按 ADR 0013/0014 落地

## 背景

Edge Assistant 的产品本质是端侧 Agent，不只是单轮模型客户端。本 ADR 最初记录时，会话只在内存中存活、推理只携带最新输入，也没有事实记忆和召回。IOS-21 先补齐关键词召回与最近历史注入；IOS-15 再按 ADR 0013 将 JSON 升级为 AES-GCM 密文 SQLite。分层记忆和细粒度生命周期已由 IOS-18 第一阶段交付；设备端 embedding 与加密索引仍待真实语料暴露需求后评审。

## 决策

1. **本地优先**：记忆全部保存在设备本地，不做静默云端同步；任何云同步必须是用户显式开启和明确授权。
2. **分层记忆**：
   - **会话记忆**：原始消息、时间戳、模型 ID、中断/失败状态。
   - **情景记忆**：用户明确叙述过的事件与任务上下文。
   - **语义记忆**：从会话中提炼的稳定事实、偏好、项目约束。
   - **工作记忆**：当前任务窗口内的活跃上下文，由预算和淘汰策略控制。
3. **显式与可解释**：重要记忆必须可查看、可编辑、可删除；Agent 引用记忆时尽量说明来源。
4. **提取链路端侧**：由本地模型完成记忆抽取和摘要；低置信度候选先存为待确认，不直接污染语义记忆。
5. **存储**：使用加密 SQLite 保存会话与结构化记忆；密钥放 Keychain，`ThisDeviceOnly`。向量索引与业务数据同设备保存，删除必须级联。
6. **召回**：第一阶段用本地字符/词特征、时间衰减和类型权重做确定性混合召回；不引入云端 embedding API，设备端 embedding 后续单独评审。
7. **生成输入**：真实引擎接收“系统提示 + 已选工作记忆 + 最近会话窗口 + 当前输入”，而不是只发当前句子。
8. **删除即消失**：用户删除记忆或全部数据时，数据库行、索引项和生成上下文缓存必须删除。

## 阶段

### IOS-15：安全持久化底座

- 已完成：系统 SQLite 保存 AES-GCM 密文，数据密钥与检索 API Key 分别保存在 Keychain。
- 已完成：会话/消息与长期事实落盘，App 重启恢复最近会话。
- 已完成：旧 JSON 迁移删除；清除数据先销毁数据密钥，再删除密文。
- 当前实现细节与取舍见 ADR 0013。

### IOS-18：Agent 记忆

- 第一阶段已完成：semantic / episodic schema、confirmed / pending 生命周期、单条确认/编辑/删除、本地混合召回与字符预算。
- 已完成：只把 confirmed 记忆注入 MLX prompt，pending 候选保持在设置页等待用户判断。
- 实现取舍见 ADR 0014；设备端 embedding 与加密索引待后续评审。

### 后续

- 记忆来源审计。
- 按主题/项目分区。
- 显式云同步（仍默认关闭）。

## 结果

Agent 长期记忆不是简单保存聊天 JSON，而是“安全持久化 + 分层记忆 + 本地召回 + 上下文预算 + 用户控制”的组合能力。IOS-15 安全持久化底座与 IOS-18 第一阶段生命周期/混合召回已交付；深层语义理解和加密索引是后续边界。
