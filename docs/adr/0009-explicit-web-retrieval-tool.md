# ADR 0009：显式联网检索工具与本地 Agent 记忆

## 状态

已采纳（2026-11-06）

## 背景

本地 MLX 推理本身不联网，也不能隐式访问互联网。Edge Assistant 是 Agent，因此需要可验证的长期记忆与可选外部信息获取。当前对话只保存在内存，推理请求只携带最新 prompt。

## 决策

### 本地记忆

1. 会话消息持久化到 Application Support；App 重启恢复（IOS-15 已升级为 AES-GCM 密文 SQLite）。
2. 从用户消息中提取长期偏好与身份事实，例如姓名、职业、喜好与“记住……”指令。
3. 事实去重保存，本地关键词召回后注入 system context；用户可清除记忆。
4. 当前使用确定性关键词召回；数据 payload 已按 IOS-15/ADR 0013 进入 AES-GCM 密文 SQLite，密钥在 Keychain。

### 联网检索

1. 推理引擎保持不联网；联网是 App 层显式工具。
2. 用户必须打开“联网检索”开关并保存搜索服务 API Key；Key 存入 Keychain。
3. 发送时 App 先把用户问题转成检索 query，调用可注入的搜索服务，再把标题、摘要、URL 作为临时检索上下文传给本地模型。
4. 来源以独立消息展示；模型回答必须提示来源于本次联网检索。
5. 检索失败时降级为纯本地回答，不伪造来源。
6. 后续若升级为模型原生 tool call，仍复用同一 `WebSearchService` 授权、来源展示和边界；当前不依赖不稳定的小模型工具调用格式。

## 后果

- 默认路径保持离线与隐私边界；只有用户显式开启后检索 query 会离开设备。
- Agent 具备跨启动的身份/偏好记忆和可选实时信息。
- 向量召回和自动多轮工具循环仍是后续任务；加密存储底座已交付。

## 非目标

- 不做隐式网页抓取或后台跟踪。
- 不把本地模型包装成“能自己浏览互联网”。
- 不在当前阶段引入云推理。
