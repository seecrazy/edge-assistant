# ADR 0012：模型安装事务、残留修复与生成可观测性

## 状态

Accepted

## 背景

真机反馈出现两个可用性问题：

1. 模型目录残留后无法重新下载。旧实现把最终目录同时当作工作目录；有 `metadata.json` 时会提前返回“已安装”，即使 manifest 关键文件缺失；没有 `metadata.json` 的残留在 UI 中不可见、不可删除。下载失败或用户取消后，用户容易进入“既不能安装，也看不到可清理项”的状态。
2. 用户要求“写一篇 800 字作文”时，回复上限仍由通用聊天默认 180 字控制；加载或解码没有阶段提示和看门狗，长时间无 token 时表现为空白气泡和静默等待。

## 目标

1. 下载写入独立 staging 目录，完整校验后原子提升为安装目录；失败不污染旧安装。
2. 支持取消/失败后幂等续传；已验证完整文件不重复下载。
3. 重新下载前先验证目标安装目录和 manifest；不完整安装自动进入修复下载。
4. 残留目录、无效 metadata 和旧安装可被枚举；UI 提供“清理残留并重新下载”。
5. 聊天能识别明确长度意图，在内存、热档位和安全上限内允许更长输出，并明确告知实际截断。
6. 首 token 和 token 间停顿有超时保护，加载/生成/截断/超时状态对用户可见，不再静默挂起。

## 非目标

- 不实现 HTTP Range 断点续传；本版本以“已完整且校验通过的文件”为续传单位。
- 不自动把不可运行模型降级为 Mock 或联网模型。
- 不承诺任意小模型能稳定写出 800 字；长度只放宽模型可生成预算，不伪造输出。
- 不改变 `critical` 热档位必须暂停推理的边界。

## 数据与状态模型

```text
<models>/
  <model-id>/metadata.json     # 仅完整安装后存在
  <model-id>/...               # 完整安装内容
  .staging/<model-id>/...      # 下载/校验工作目录，可保留用于幂等续传
```

- `InstallHealth`：`installed`、`incomplete(metadata + missing/bad files)`、`residual(no metadata)`。
- `cleanupResidualInstall(id)` 只删除无 metadata 或非激活的无效安装；不会删除健康安装。
- 生成流继续使用 `InferenceEvent`；超时以 `EngineError.timeout(stage)` 抛出。

## 关键交互

### 安装

1. 解析 manifest，检查磁盘空间。
2. 若已有健康安装且文件大小/摘要匹配，幂等返回。
3. 否则把逐个文件下载到 `.staging/<id>`，下载后执行结构、大小、SHA-256 校验；主源失败继续镜像回退。
4. 全部文件通过后原子替换/创建 `<id>`，写入 metadata；staging 清理。
5. 用户取消或网络/校验失败保留 staging；下一次下载覆盖未通过校验的文件并复用已完整文件。
6. App 启动和商店刷新时枚举最终残留与中断 staging；用户显式清理后可重新下载。

### 生成

1. 发送后先显示“正在准备本地推理”。
2. 系统提示保持简洁，但解析用户输入中的 800/1000 等明确字数意图；普通档上限提升到 2000 字，warm/hot 仍分别限制 120/90 字。
3. token 预算按目标字符数上浮，避免中文被 `chars / 2` 提前截断。
4. 首 token 超过 60 秒或相邻 token 超过 45 秒抛出可读超时；用户可停止。
5. 若因长度上限截断，追加系统消息“已达本次安全上限”，不把截断伪装成完整回答。

## 边界与错误处理

- checksum/size 失败：允许镜像重试；两次失败保留 staging，下一次下载复用完整文件并覆盖坏文件，同时显示具体文件。
- 激活仍做目录预检和真实容器预热；失败模型不得切为 active。
- 超时错误记录到 engine metrics/error；UI 不清空用户输入，只禁用并发发送直到任务结束。
- 清理操作需要显式用户触发；启动只标记和提示，不静默删除可见模型。

## 验收清单

- [x] 校验失败下载不产生 `metadata.json`。
- [x] 取消后重试不重复下载已完整文件。
- [x] 带 metadata 但缺 manifest 文件的安装会自动修复。
- [x] 无 metadata 残留与中断 staging 可枚举、可清理、清理后可下载。
- [x] “写一篇 800 字作文”在 normal 档的请求预算不低于 800 字。
- [x] Mock/真实引擎的流式挂起会触发超时而不是无限等待。
- [x] Swift 域层测试与 iOS App 构建通过。
