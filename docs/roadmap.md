# Edge Assistant Roadmap

## 当前状态

**阶段：M1 推理抽象与模型资产进行中**

已交付：

- 产品目标、非目标和系统架构设计。
- 端侧优先 ADR。
- 模型分级与资产分发 ADR。
- 温控与功耗分级降级 ADR。
- 无第三方依赖的浏览器原型。
- 核心状态机、机型分级和延迟预算的单元测试。
- `InferenceEngine` 平台无关参考实现。
- 模型资产注册、SHA-256 校验、失败保护与单步回滚。
- 自带模型资产目录、自动装载编排器与“安装即内置”原型演示。
- 上下文预算、工具调用、温控降级、数据导出与安全设计（`docs/design.md` §5.5–§5.7、§7.1–§7.2）。
- **iOS 工作流已启动**：iOS 详细设计（`docs/design-ios.md`）、技术选型 ADR 0004、域层 Swift Package `EdgeAssistantCore`（`swift test` 56 项全绿）；进度与任务清单见 `docs/progress.md`。
- **IOS-16 热状态已接入**：系统热通知、UI 热档位徽标、`critical` 推理门控与 60 秒逐级迟滞恢复已实现。
- **IOS-13 MLX/VLM 后端开发完成**：MLX Swift LM `3.32.3` 已接入文本与 VLM 工厂；商店 MLX 模型激活后走真实引擎，内置模拟资产继续走 Mock，商店支持显式切回 Mock。iOS Simulator 构建与纯域测试通过，真实模型输出等待真机显式下载验收。
- **IOS-20 联网模型发现开发完成**：HuggingFace 搜索、`config.json` 架构探测、文件树 manifest、兼容性白名单、空间门控与流式 SHA-256 已实现。Gemma 4 E2B 标记可用；MiniCPM-V 4.7 标记不支持；原生 MNN Pocket 标记需转换。真实下载/推理待真机。
- **IOS-23 运行时感知发现已交付**：必须先命中 MLX 权重布局再检查 registry 架构；搜索并行、最多探测 12 个候选、单候选失败不阻断；普通词自动扩展 MLX-community 量化变体；主源 manifest 不可用时回退镜像；下载显示解析/进度/自动激活状态，硬件档位只提示风险。真实下载/推理待真机。
- **IOS-23b 商店 UI 已优化**：可运行与轻量模型优先排序，模型卡显示下载体积、轻量/中量/重量内存负担与本机风险；聊天页新增商店直达、多行输入和热停顿提示。
- **IOS-15 安全持久化底座已交付**：会话与长期事实写入 AES-GCM 密文 SQLite，旧 JSON 自动迁移；Agent 数据密钥与 Tavily Key 独立保存，API Key 可删除，清除数据先销毁数据密钥。
- **IOS-18 第一阶段已交付**：semantic / episodic 分层、confirmed / pending 生命周期、单条确认/编辑/删除、本地字符/词 + 时间 + 类型混合召回与 5 条 / 1200 字工作记忆预算。云端 embedding、设备端 embedding、加密索引和主题分区仍未实现。
- **IOS-21 Agent 记忆与显式检索开发完成**：关键词召回注入 prompt；联网检索默认关闭，开启后走 Tavily、Key 入 Keychain、来源带 URL 展示并失败降级。
- **IOS-22 模型预检已交付**：下载时解析 JSON/Safetensors/Jinja 结构，激活时预检本地目录并真实预热 MLX/VLM 容器；坏文件不再进入“首聊才失败”。51 项 Swift 测试和 iOS 构建通过。
- **IOS-23c 网络回退已交付**：config、manifest 和权重都支持 `hf-mirror` 回退；静态 supported 模型解析完整 manifest，避免缺 chat template；旧安装缺必需文件会自动修复。远程候选也不会再因主源探测失败全部停在“待检查”。
- **IOS-24 可靠性增强已交付**：模型下载改为 staging 事务并原子入库，残留/中断缓存/不完整安装可枚举、清理或修复；聊天支持明确 800 字长度预算（normal 最高 2000 字），显示推理阶段并在无进展时超时报错。56 项 Swift 测试与 iOS Simulator 构建通过。
- **IOS-19 专用图标已交付**：深色端侧底座、对话气泡与本地神经网络视觉已进 AppIcon asset catalog，并在模拟器主屏验证。

浏览器原型明确不是完整移动端实现，不包含真实模型推理、真实电话能力或摄像头采集。iOS 已包含 MLX/VLM 文字推理后端，但真机模型验收和三档基准尚未完成。
